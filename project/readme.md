# Финансовый Микросервис (Gateway & Ledger)

Проект представляет собой модульное приложение на Go, разделенное на два ключевых сервиса: **API Gateway** (HTTP-сервер) и **Ledger** (сервис учета транзакций с собственным хранилищем в памяти).

## 📁 Структура проекта

```text
project/

├── api-gateway/             # Сервис шлюза (HTTP API)
│   ├── go.mod
│   └── server.go            # HTTP-сервер на порту 8080
│
└── ledger/                  # Сервис учёта (финансовая логика)
    ├── go.mod
    ├── main.go              # Точка входа для Ledger
    ├── budgets.json         # Бюджеты в формате JSON
    ├── models/
    │   ├── transaction.go   # Структура Transaction
    │   └── budget.go        # Структура Budget
    └── repository/
        └── memory.go        # Хранилище Storage в памяти
```

## 🚀 Как запустить и проверить сервисы

### 1. Запуск API Gateway (HTTP-сервер)
Перейдите в папку шлюза и запустите сервер:
```bash
cd api-gateway
go run main.go
```
* **Проверка работы:** Откройте браузер по адресу [http://localhost:8080/ping](http://localhost:8080/ping). Вы должны увидеть ответ `pong` со статусом `200 OK`.
* **Остановка сервера:** Нажмите `Ctrl + C` в терминале.

### 2. Запуск Ledger Service (Логика и Репозиторий)
Откройте соседний терминал, перейдите в папку ledger и запустите его:
```bash
cd ledger
go run main.go
```
* **Что делает сервис:** Инициализирует репозиторий, проводит валидацию бизнес-логики (проверяет транзакции на нулевую сумму и соответсвие бюджту) и выводит список всех сохраненных операций через встроенную функцию `ListTransactions()` и всех сохраненных бюджетов через `ListBudgets(), а также может загружать бюджеты из файла json.

## 🧪 Тест-кейсы в `runBudgetScenario()`

В хранилище по умолчанию уже существуют бюджеты для категорий **«еда»** и **«транспорт»**.

Проверяются следующие сценарии:

1. **Обновление бюджета «еда»** — через `SetBudget()` добавляется бюджет «еда» на 1–31 октября с лимитом 5000. Проверяется отсутствие дубликата при совпадении периода.
2. **Загрузка из JSON** — дополнительные бюджеты загружаются из файла `budgets.json`.
3. **Транзакция 3000** — успешно добавляется в октябре и не превышает лимит.
4. **Транзакция 2500** — отклоняется, так как превышает общий бюджет категории «еда».
5. **Транзакция 2000 в ноябре** — успешно добавляется, так как находится вне периода октябрьского бюджета.
6. **Транзакция 4000 «развлечения»** — успешно добавляется для категории без бюджета.
7. **Проверка результата** — выводятся список бюджетов через `ListBudgets()` и список сохранённых транзакций через `ListTransactions()`.


# Финансовый Микросервис (Gateway & Ledger)

Проект представляет собой модульное приложение на Go, разделённое на два ключевых сервиса:

* **API Gateway** — HTTP-сервер, принимающий внешние запросы.
* **Ledger** — сервис учёта финансовых транзакций с хранилищем в памяти и поддержкой бюджетов.
